# HyperFetch

A fast, customizable system information tool with a real-time rotating 3D ASCII logo.

## Features

- 🎨 Theme support (Rose Pine by default)
- 🖥️ Real-time rotating 3D ASCII logos
- ⚡ Fast
- 🧩 Modular architecture
- 🎭 Nerd Font icons
- 🪟 Wayland friendly
- 🐧 Linux first
