# HyperFetch

> A fast, customizable system information tool with a real-time rotating 3D ASCII logo.

![Preview](screenshots/preview.png)

## Features

- 🎨 Theme support
- 🌸 Rose Pine by default
- 🖥️ Real-time rotating ASCII logos
- ⚡ Fast
- 🧩 Modular architecture
- 🪟 Wayland friendly

## Building

```bash
cmake -B build
cmake --build build
./build/hyperfetch
```
